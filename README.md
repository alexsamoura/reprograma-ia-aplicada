Este repositório é dedicado à documentação de aprendizados, engenharia de prompt, testes e aplicação prática de Inteligência Artificial no processo de Product Design e UI/UX durante o curso da **{reprograma}**.

# Estudos de IA Aplicada

---

## 📌 Objetivos
- Mapear fluxos de trabalho que unem IA e Design de Produto.
- Criar uma biblioteca de prompts eficientes para pesquisa, wireframing e documentação.
- Registrar os desafios práticos e aprendizados de cada semana.

---

## 📁 Estrutura do Repositório

| Pasta | Descrição |
| :--- | :--- |
| `01-prompts/` | Biblioteca de prompts estruturados para UI/UX e análise. |
| `02-experimentos/` | Prototipagem, testes com ferramentas de IA e resultados visuais. |
| `03-diario-de-bordo/` | Resumos por módulo, aprendizados diários e soluções de problemas. |
